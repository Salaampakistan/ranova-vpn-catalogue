RANOVA VPN PRO v1.0 RC2 Release Candidate

RANOVA VPN PRO is a standalone Android VPN client with its own Android VpnService
and an embedded OpenVPN3-compatible tunnel engine. The end user does not need a
separate OpenVPN application installed.

The automatic server catalogue is maintained in this repository and uses public
VPN Gate relay data. The application includes Smart Connect, bounded auto-failover,
dead-server cooldown, country/location selection, account access control, a fixed
dashboard header, password visibility controls, RANOVA branding, and connection
status notifications.

Production Android application id:
com.ranova.vpnpro

Internal Java namespace remains com.ranova.vpnpro.beta for source-compatibility
with the validated standalone implementation; this is not the installed package id.
